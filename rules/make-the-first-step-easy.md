# Make the first step easy

**Why.** When something goes unused, I check those three first. Each has a different fix. Setup that takes an hour isn't solved by a better pitch.

**Example.** A tool that needs a config file before it does anything can lose people at the config file. A working default fixes that, where a better tutorial wouldn't.
