# Rough, not hollow

**Why.** Some questions only real use can answer, so polishing those first is guessing. Others you can reason through beforehand: what the person will feel at each step, and which detail creates that feeling. Ship without that detail and you've shipped a different, worse idea. "We'll add it later" rarely arrives.

**Example.** A copy-to-clipboard button without the "Copied" confirmation leaves people clicking twice and wondering. The confirmation is the feature.
